# Vobaca JP Phrasebook

零基礎也能使用的《排球少年!! Vobaca!! BREAK》日本賽對戰日語速查工具。

## 功能

- 100 句對戰日語
- 中文、日文、零基礎讀音與輔助手勢
- 分類篩選與即時搜尋
- 日文語音播放與句子複製
- 必背模式、列印、手機版與深色模式

## 公開網站

在 GitHub repository 的 **Settings → Pages**，將來源設為 **Deploy from a branch**，選擇 `main` 與 `/ (root)` 後儲存。
