# Vobaca JP Phrasebook

零基礎也能使用的《排球少年!! Vobaca!! BREAK》日本賽對戰日語速查工具。

## 公開網站

https://amy-tung.github.io/vobaca-jp-phrasebook/

## 功能

- 100 句對戰日語
- 中文、日文、零基礎讀音與輔助手勢
- 分類篩選與即時搜尋
- 日文語音播放與句子複製
- 必背模式、列印、手機版與深色模式

## 發布設定

GitHub Pages 使用 `main` branch 的 `/ (root)` 作為網站來源。提交到 `main` 根目錄的 `index.html` 與相關檔案會自動重新發布。
